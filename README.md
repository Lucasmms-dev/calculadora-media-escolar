# 📚 Calculadora de Média Interativa

Este projeto é uma ferramenta web para o cálculo de médias escolares, desenvolvida com o objetivo de aplicar conceitos fundamentais de Front-End e lógica de programação.

## 🎯 Objetivo do Projeto
Providenciar uma interface simples onde o utilizador insere o seu nome e duas notas, recebendo de imediato o cálculo da média e o seu status (Aprovado ou Reprovado) com feedback visual.

## 🛠️ Tecnologias Utilizadas
- **HTML5**: Estrutura semântica e formulários.
- **CSS3**: Design responsivo, uso de gradientes e sombras para profundidade.
- **JavaScript (ES6)**: Manipulação do DOM, tratamento de dados numéricos e lógica condicional.

## ⚖️ Análise Estratégica & Aprendizagem
Durante o desenvolvimento, foquei-me em três pilares principais:
1. **Separação de Camadas**: Organização do projeto em ficheiros distintos (`.html`, `.css`, `.js`) para facilitar a manutenção.
2. **Tratamento de Dados**: Utilização do método `Number()` para garantir operações matemáticas precisas e `.toFixed(1)` para uma interface limpa.
3. **Experiência do Utilizador (UX)**: Implementação de caminhos relativos para recursos (como favicons e imagens) e organização de layout com o modelo de caixa (Box Model).
